# Aroosh Elegance

Build a modern, elegant e-commerce website for "Aroosh Collections", a women's fashion boutique selling clothing and shoes based in Pakistan.

BRAND & THEME:

- Dark theme throughout: background near-black (#0F0509), card/section background (#1A0A0F), borders (#3D1E29)

- Accent colors: gold (#C9A24B) for highlights/buttons/prices, deep maroon (#7A1F3D) for secondary buttons and accents, off-white/cream (#F5E9EC) for headings, muted rose (#9C6B7A) for secondary text

- Elegant serif font for headings (e.g. Playfair Display or similar), clean sans-serif for body text

- Logo: gold text "AROOSH" with "COLLECTIONS" below in smaller letter-spaced text, with a small decorative flower/petal icon above, on black background — treat this as the brand mark style

PAGES & SECTIONS NEEDED:

1. Header/Navbar:

 - Logo on the left

 - Navigation links: Home, Shop, Boutique, Shoes, About, Contact

 - A shopping cart icon on the right

 - A subtle "Staff Login" text link in the top corner (small, unobtrusive)

 - Sticky on scroll

2. Hero banner section:

 - Full-width hero image/banner with an elegant woman's fashion aesthetic (soft lighting, boutique feel)

 - Overlay text: "Aroosh Collections" tagline like "Timeless Elegance, Modern Grace"

 - A call-to-action button "Shop Now" in gold

3. Category showcase:

 - Two large category cards side by side: "Women's Clothing" and "Shoes", each with a representative image and a "Shop Now" link

4. Featured products grid:

 - Section titled "New Arrivals" or "Featured Products"

 - Show 6-8 sample product cards in a responsive grid, each with: product image placeholder, product name, category tag, price in PKR, "Add to Cart" button
